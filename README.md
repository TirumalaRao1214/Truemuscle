# True Muscle Fitness Hub

A premium, highly polished static fitness platform inspired by modern fitness brands, designed specifically for **True Muscle Fitness Hub** in Guntur, Andhra Pradesh.

## Features
- **Cinematic Hero**: Full-bleed strength-training visuals with high-impact typography and animated stats counters.
- **Horizontal Category Carousel**: Cult.fit-style touch & drag scrollable workout disciplines.
- **Editorial Programs Showcase**: Detailed breakdown of Muscle Building, Fat Loss, Strength, and Personal Training.
- **Gym Experience Mosaic**: Visual showcase of the facility, free weights, cardio decks, and biomechanical machines.
- **Why True Muscle**: Numbered progressive feature cards (01 Train Harder, 02 Move Better, 03 Get Stronger, 04 Stay Consistent).
- **Meet Your Coaches**: Horizontal trainer profile slider with credentials and booking triggers.
- **Before / After Transformation Slider**: Interactive draggable comparison slider.
- **Interactive BMI Calculator**: Live metric calculation with visual gauge and personalized advice.
- **Membership Pricing**: Transparent plan tiers with instant WhatsApp inquiry routing.
- **Direct WhatsApp Lead Engine & Free Trial Modal**: No database or backend required.
- **Fully Responsive**: Mobile-first design with bottom app bar for smartphones (320px to 4K).
- **Local SEO & Schema Markup**: Pre-configured `LocalBusiness` JSON-LD and Open Graph tags.

---

## Tech Stack
- **HTML5** (Semantic structure & SEO metadata)
- **CSS3** (Custom properties, grid, flexbox, glassmorphism, responsive breakpoints)
- **JavaScript** (Vanilla ES6 modules for animations, carousel, BMI calculation, and WhatsApp lead routing)

## Deployment
This static website runs immediately by opening `index.html` in any browser and can be deployed directly to Render Static Sites, GitHub Pages, Vercel, or Netlify.
